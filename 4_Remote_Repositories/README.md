# Lesson 4: Working with Remote Repositories

Remote repositories allow multiple developers to **collaborate** on the same project.  
In this lesson, you’ll learn how to connect to remote repositories, synchronize changes, and push your local commits.

---

### 📚 Topics Covered
1. Concept of remote repositories  
2. Cloning a repository  
3. Fetching and pulling changes  
4. Pushing commits  
5. Setting up GitHub connection (HTTPS & SSH)  

---

### 🧩 Expected Outcome
By the end of this lesson, you will be able to:
- Clone remote repositories  
- Fetch and pull updates  
- Push your commits to a remote repository  
- Configure Git to authenticate with GitHub
