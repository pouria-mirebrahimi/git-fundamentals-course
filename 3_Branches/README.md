# Lesson 3: Working with Git Branches

Branches allow you to work on **different features or experiments** without affecting the main codebase.  

In this lesson, you will learn:
- How to create, switch, and delete branches
- How to merge branches and resolve conflicts
- An introduction to rebase

---

### 📚 Topics Covered
1. Branch concept and workflow
2. Creating and switching branches
3. Merging branches
4. Fast-forward vs non-fast-forward merges
5. Introduction to rebase

---

### 🧩 Expected Outcome
By the end of this lesson, you will be able to:
- Create branches for new features
- Switch between branches seamlessly
- Merge changes safely
- Understand how branching fits into collaborative workflows
