## Exercise 5: Resolve Merge Conflicts (Optional Challenge)

**Instructions:**

1. Make changes in the same file on `feature2` and `main`
2. Merge `feature2` into `main`:

```bash
git merge feature2
```

3. Resolve conflicts manually, then:

```bash
git add <file>
git commit
```

**Expected Outcome:**

* Conflicts are resolved
* Merge is successful
