## Exercise 1: View and Create Branches

**Objective:** List current branches and create a new one.

**Instructions:**
1. Check current branch:
```bash
git branch
````

2. Create a new branch:

```bash
git branch feature1
```

3. Switch to it:

```bash
git switch feature1
```

**Expected Outcome:**

* `feature1` branch exists
* You are on `feature1`
