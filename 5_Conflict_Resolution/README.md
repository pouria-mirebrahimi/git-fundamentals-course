# Lesson 5: Conflict Resolution in Git

When multiple people work on the same project, **merge conflicts** are inevitable.  
This lesson will teach you how to detect, resolve, and prevent conflicts in team workflows.

---

### 📚 Topics Covered
1. What causes merge conflicts  
2. How to detect conflicts  
3. How to resolve conflicts manually and with tools  
4. Preventing conflicts through best practices  

---

### 🧩 Expected Outcome
By the end of this lesson, you will be able to:
- Identify merge conflicts  
- Resolve conflicts manually or using a merge tool  
- Complete merges successfully  
- Use strategies to minimize future conflicts
