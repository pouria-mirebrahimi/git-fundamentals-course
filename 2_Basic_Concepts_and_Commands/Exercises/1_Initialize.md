## Exercise 1: Initialize and Check Repository

**Objective:** Create a repository and verify it.

**Instructions:**
1. Create a folder:
```bash
mkdir lesson2-repo
cd lesson2-repo
````

2. Initialize Git:

```bash
git init
```

3. Check status:

```bash
git status
```

**Expected Outcome:**

* `.git` folder exists
* Status shows "nothing to commit"
