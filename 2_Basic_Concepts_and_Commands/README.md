# Lesson 2: Basic Git Concepts and Commands

In this lesson, we’ll explore the core concepts of Git and the most commonly used commands.  
By the end, you’ll be able to track changes, make commits, and understand Git’s version control workflow.

---

### 📚 Topics Covered
1. Core Git concepts (repository, commit, staging area)  
2. Basic commands: `git init`, `git status`, `git add`, `git commit`, `git log`  
3. Undoing changes: `git reset`, `git restore`, `git revert`  
4. Understanding the commit history and workflow  

---

### 🧩 Expected Outcome
After completing this lesson, you’ll be able to:
- Track changes in a project using Git  
- Add and commit files properly  
- View commit history and details  
- Undo mistakes safely
