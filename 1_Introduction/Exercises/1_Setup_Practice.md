## Exercise 1: Verify Git Installation

**Objective:** Confirm that Git is installed correctly on your system.

**Instructions:**
1. Open your terminal (Command Prompt, PowerShell, or Terminal).
2. Type the following command:
```bash
git --version
````

**Expected Outcome:**

* Terminal shows your Git version, e.g., `git version 2.42.0`.

**Hints:**

* If you see an error, check your installation path or reinstall Git.
