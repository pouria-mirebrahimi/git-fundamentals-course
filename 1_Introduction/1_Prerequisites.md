# Prerequisites

Before starting this lesson, make sure you have the following:

### 💻 Basic Skills
- Familiarity with using the **command line** (Terminal or PowerShell)
- Understanding of **folders and files** on your computer

### 🧰 Required Tools
- Internet connection to download Git
- A **text editor** (Visual Studio Code recommended)
- Administrative access to install software

### 🧾 Optional but Recommended
- A **GitHub account** (we’ll connect to it later)
- Installed **VS Code Git extension**
- Basic knowledge of how projects are organized (src, docs, etc.)
