# Lesson 1: Installing and Initial Setup of Git

Welcome to the first lesson of the Git Fundamentals course!

In this lesson, you’ll learn how to:
- Install Git on your operating system (Windows, macOS, or Linux)
- Configure Git for the first time
- Verify your installation and settings
- Understand the `.git` folder and its purpose

By the end of this module, you’ll have Git properly installed and ready to use for version control.

---

### 📚 Topics Covered
1. Prerequisites  
2. Installing Git  
3. Initial Configuration  
4. Verifying the Setup  
5. First Git Project  

---

### 🧩 Expected Outcome
After completing this lesson, you’ll be able to:
- Use Git from the command line  
- Set up your name and email in Git  
- Create your first local repository  
- Understand where Git stores your project’s metadata
